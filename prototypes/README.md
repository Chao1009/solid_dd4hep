# Visualization prototypes (feasibility study, November 2026)

Working prototypes behind the visualization feasibility study: drawings without the DAWNFILE driver, event displays
with calorimeter energy, and animation. They are reference material for the implementation, not supported tools.

- `vis_study/FEASIBILITY.md` is the study: findings, options, plan and file list.
- `vis_study/*/REPORT.md` are the reports of the four investigations.
- `vis_study/images/` holds a few sample outputs.
- Paths in the files were rewritten: `$SCRATCH` stands for the temporary directory the study ran in.
